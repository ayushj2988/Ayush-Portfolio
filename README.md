# Desk portfolio (react-three-fiber)

    npm install
    npm run dev

- `src/config.ts`: every link (GitHub, LinkedIn, LeetCode, email, project urls).
- `src/scene/items.ts`: everything on the desk, with positions in scene units.
- `src/scene/draw.ts`: how each object is painted.
- `public/resume.pdf`: your resume, shown at `/resume`.
- Hosting: add an SPA fallback so `/resume` loads on refresh.
